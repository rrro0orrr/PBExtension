# PBExtension

A Paperback repository of manga, comic and novel extensions, maintained by [rrro0orrr](https://github.com/rrro0orrr).

This repository is a fork of [**KakarotExtension**](https://github.com/karrot0/KakarotExtension) by **Karrot** ([@karrot0](https://github.com/karrot0)). Most of the extensions here started from Karrot's work; see [Credits](#-credits) below.

## 🚀 Installation

1. Open Paperback
2. Add this repository using [this link](https://rrro0orrr.github.io/PBExtension/0.9/stable/)
3. Install and enjoy reading!
